# Obsidian Motorcycles Ltd visual rules

- All prominent headings and subheadings must use Obsidian's original white, hand-painted, jagged-edged, distressed brush artwork.
- Never replace a branded heading with a normal web font, horror font, handwritten font, or an approximate “grunge” font.
- Prefer an existing complete `BrushHeading` phrase asset when it is accurate, legible, generously padded and not cropped.
- Ordinary headings are assembled by `app/BrandLettering.tsx` from the original painted artwork in `public/brand-glyphs/`; preserve this system for exact new wording.
- Any new generated heading asset must have exact text, a genuine transparent background, and generous clear padding on every edge so no brush stroke is clipped.
- Body copy, navigation, controls and legal text may use the established readable site fonts; this exception does not apply to prominent headings.
