# Obsidian Motorcycles Ltd Website

Official website source for Obsidian Motorcycles Ltd.

Current hosted site: https://obsidian-motorcycles.obsidian2026.chatgpt.site

## Development

- Node.js 22.13 or newer
- Install dependencies with `npm ci`
- Run locally with `npm run dev`
- Build with `npm run build`

The website is built with Vinext and React. Main page content is in `app/`.
